# AGENTS.md

## Build & Dev

```sh
npm run dev          # start the Astro dev server on http://localhost:4321
npm run build        # produce the production build in dist/
npm run preview      # serve the production build locally
```

## Lint & Format

```sh
npm run typecheck    # astro check — static types + Astro component checks
npm run lint         # eslint .
npm run format       # prettier --write .
```

## Test

```sh
npm test             # node --test ./src/**/*.test.ts
```
